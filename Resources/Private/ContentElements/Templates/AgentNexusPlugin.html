Generic content-element wrapper for every Agent Nexus frontend plugin. lib.contentElement gives us the site's element frame (spacing, frame class, id anchor); this template only adds the standard element header and then renders the plugin itself as cObj "20" (an EXTBASEPLUGIN, see the site set's setup.typoscript). The header partial is optional so the template also works in installations whose partial paths do not carry fluid_styled_content's Header/All.
