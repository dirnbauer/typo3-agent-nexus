    What is A2UI?

    A2UI (Agent-to-User Interface) is an open protocol for letting an AI agent describe a user interface as declarative JSON. The agent never ships HTML or scripts — it sends a surface, and a trusted client renders it with native components. That separation is what makes agent-authored UI safe, portable and consistent.

    1 · Emit
    The agent emits an A2UI v1.0 surface (a flat list of components + a data model).
    2 · Render
    The client renders it with native, trusted backend components — only the catalog below is allowed.
    3 · Signal
    User input updates the data model; an action sends a structured userAction back.
    4 · Reason
    The agent reacts to the signal and can update the surface — closing the loop.
