Agent Nexus

A field guide to the agent-protocol family

This module is a study guide and playground hub for the protocols agents use to talk to tools, to each other, to users, to UIs, to merchants and to payments. Every protocol gets a definition, a sequence diagram, a live backend playground, and a real plugin on the demo site — commerce flows are simulated, and a human gate stands before every write.
