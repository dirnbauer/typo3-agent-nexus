What is UCP?

UCP (Universal Commerce Protocol) is the emerging layer for agentic commerce: a merchant publishes a machine-readable manifest and catalog, and a shopping agent discovers it, builds a cart and runs a checkout on the shopper's behalf.

The safeguard is the authorization gate: the agent assembles the order but a human (or a signed mandate — see AP2) must authorize it before any purchase. In this demo every order is simulated — no payment is ever taken.
