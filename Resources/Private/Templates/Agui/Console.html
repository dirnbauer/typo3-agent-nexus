What is AG-UI?

AG-UI (Agent-User Interaction Protocol) standardises how a backend agent streams real-time events to a frontend so people stay in the loop during long tasks. The frontend POSTs a RunAgentInput (and declares which tools the agent may use), and the agent replies with an ordered stream of typed events over SSE.

The trust model is built in: the UI declares the tools, sensitive actions are gated behind a human-in-the-loop confirmation (a tool the user must answer), and nothing is written until you approve.
